# Internship REST API

Node.js and Express REST API with SQLite persistence, input validation, and pagination for internship records.

## Features
- **CRUD Operations**: Complete endpoints to Create, Read, Update, and Delete internships.
- **Persistence**: SQLite database with automated seed data generation.
- **Pagination & Filtering**: Query parameters support pagination (`page`, `limit`) and domain filtering (`domain`).
- **Validation**: Input checking with proper HTTP status codes (`400 Bad Request`, `404 Not Found`, `201 Created`).
